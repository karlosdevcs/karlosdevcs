# 👨🏻‍💻 Karlos Dâmaso

**`Desenvolvedor .NET Júnior | PostgreSQL & Banco de Dados`**

Me chamo Karlos Dâmaso e sou desenvolvedor júnior focado no ecossistema **.NET** com **C#**. Venho de uma base sólida em **banco de dados**: já atuei como **DBA PostgreSQL**, cuidando de modelagem, otimização de consultas, índices, backups, rotinas de manutenção e performance. Atualmente sou **Analista de Integração de Dados**, trabalhando com **Oracle**, **PHP** e **AWS**. Em paralelo, uno essa experiência com o desenvolvimento back-end, criando APIs e aplicações que conversam bem com o banco, e uso **Docker** para padronizar meus ambientes.

- 🐘 Experiência ampla com **PostgreSQL** e **SQL**: modelagem, tuning, *query plans*, procedures e administração
- 💼 **Analista de Integração de Dados**: integrações entre sistemas com **Oracle**, **PostgreSQL**, **PHP** e **AWS**
- 🔭 Desenvolvendo APIs REST com **C#** e **ASP.NET Core**
- 🌱 Aprofundando em **C#**: orientação a objetos, LINQ, programação assíncrona (`async/await`), Entity Framework Core e boas práticas (SOLID, Clean Code)
- 💬 Pode me perguntar sobre PostgreSQL, Oracle, SQL, integração e modelagem de dados e C#
